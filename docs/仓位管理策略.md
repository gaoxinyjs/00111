# 仓位管理策略（针对15分钟K线优化）

## 📊 策略概述

针对15分钟K线交易，设计了一套灵活的仓位管理策略，支持固定USDT下单和比例下单两种模式，并根据多个因子动态调整仓位大小。

## 🎯 核心原则

1. **风险控制优先**：单笔风险不超过账户的2%
2. **灵活调整**：根据信号强度、信心度、市场状态动态调整
3. **回撤保护**：根据账户回撤情况降低仓位
4. **固定/比例可选**：支持固定USDT下单（稳定）和比例下单（灵活）

## 📋 仓位计算策略

### 策略1：固定USDT下单（推荐）

**优势**：
- 每次交易风险固定，易于管理
- 不受账户余额变化影响
- 适合15分钟K线频繁交易

**配置**：
```yaml
position_management:
  mode: "fixed_usdt"  # 固定USDT模式
  fixed_usdt_per_trade: 1000  # 每次固定1000 USDT
  min_usdt_per_trade: 500  # 最小500 USDT
  max_usdt_per_trade: 2000  # 最大2000 USDT
```

**仓位计算**：
```
合约张数 = 固定USDT / (价格 × 合约乘数)
```

**调整因子**：
- 信心度倍数：HIGH 1.5倍，MEDIUM 1.0倍，LOW 0.5倍
- 信号强度倍数：>=0.7 1.2倍，>=0.6 1.0倍，>=0.5 0.8倍
- 入场时机倍数：>=70分 1.1倍，>=60分 1.0倍，>=50分 0.9倍
- 市场波动率倍数：低波动 1.2倍，中波动 1.0倍，高波动 0.8倍

**最终USDT**：
```
最终USDT = 固定USDT × 信心度倍数 × 信号强度倍数 × 入场时机倍数 × 波动率倍数
```

### 策略2：比例下单

**优势**：
- 根据账户余额自动调整
- 适合账户余额变化较大的情况
- 更灵活

**配置**：
```yaml
position_management:
  mode: "percentage"  # 比例模式
  base_position_size: 0.05  # 基础仓位5%
  max_position_size: 0.15  # 最大仓位15%（针对15分钟K线）
  min_position_size: 0.02  # 最小仓位2%
```

**仓位计算**：
```
基础仓位 = 账户余额 × 基础仓位比例
最终仓位 = 基础仓位 × 信号强度系数 × 信心度系数 × 入场时机系数 × 波动率系数
```

### 策略3：混合模式（推荐）

**优势**：
- 结合固定USDT和比例的优点
- 根据市场状态自动切换

**配置**：
```yaml
position_management:
  mode: "hybrid"  # 混合模式
  default_mode: "fixed_usdt"  # 默认固定USDT
  switch_threshold: 0.10  # 账户余额变化10%时切换
  fixed_usdt_per_trade: 1000
  base_position_size: 0.05
```

## 🔧 动态调整因子

### 1. 信心度调整（DeepSeek信心度）

| 信心度 | 倍数 | 说明 |
|--------|------|------|
| HIGH (>=0.8) | 1.5倍 | 高信心，加大仓位 |
| MEDIUM (>=0.6) | 1.0倍 | 中等信心，标准仓位 |
| LOW (<0.6) | 0.5倍 | 低信心，减少仓位 |

### 2. 信号强度调整

| 信号强度 | 倍数 | 说明 |
|----------|------|------|
| >=0.7 | 1.2倍 | 强信号，加大仓位 |
| >=0.6 | 1.0倍 | 中等强信号，标准仓位 |
| >=0.5 | 0.8倍 | 中等信号，减少仓位 |
| >=0.4 | 0.6倍 | 弱信号，减少仓位 |
| <0.4 | 0.4倍 | 很弱信号，最小仓位 |

### 3. 入场时机调整（入场评分）

| 入场评分 | 倍数 | 说明 |
|----------|------|------|
| >=70分 | 1.1倍 | 优秀时机，小幅加仓 |
| >=60分 | 1.0倍 | 良好时机，标准仓位 |
| >=50分 | 0.9倍 | 一般时机，小幅减仓 |
| <50分 | 0.8倍 | 较差时机，减少仓位 |

### 4. 市场波动率调整

| 波动率 | 倍数 | 说明 |
|--------|------|------|
| <2% | 1.2倍 | 低波动，加大仓位 |
| 2-4% | 1.0倍 | 中波动，标准仓位 |
| 4-6% | 0.8倍 | 高波动，减少仓位 |
| >6% | 0.6倍 | 极高波动，大幅减仓 |

### 5. 趋势强度调整

| 趋势 | 倍数 | 说明 |
|------|------|------|
| 强势上涨/下跌 | 1.2倍 | 强趋势，加大仓位 |
| 温和上涨/下跌 | 1.0倍 | 中等趋势，标准仓位 |
| 震荡整理 | 0.8倍 | 震荡市场，减少仓位 |

### 6. 回撤控制调整

| 回撤 | 倍数 | 说明 |
|------|------|------|
| <5% | 1.0倍 | 正常，标准仓位 |
| 5-10% | 0.8倍 | 小幅回撤，减少仓位 |
| 10-15% | 0.6倍 | 中等回撤，大幅减仓 |
| 15-20% | 0.4倍 | 大幅回撤，最小仓位 |
| >20% | 0.2倍 | 严重回撤，暂停交易 |

## 📈 仓位计算示例


### 示例2：比例模式

**条件**：
- 账户余额：10000 USDT
- 基础仓位：5%
- DeepSeek信心度：0.65 (MEDIUM)
- 信号强度：0.60
- 入场评分：65分
- 市场波动率：4%
- 回撤：8%

**计算**：
```
基础仓位 = 10000 × 5% = 500 USDT
信心度系数 = 1.0 (MEDIUM)
信号强度系数 = 1.0 (>=0.6)
入场时机系数 = 1.0 (>=60分)
波动率系数 = 0.8 (4-6%)
回撤系数 = 0.8 (5-10%)

最终仓位 = 500 × 1.0 × 1.0 × 1.0 × 0.8 × 0.8 = 320 USDT
仓位比例 = 320 / 10000 = 3.2%
```

## 🛡️ 风险控制

### 单笔风险限制

```
单笔最大风险 = 账户余额 × 2%
如果 最终仓位 × 1%止损 > 单笔最大风险，则降低仓位
```

### 总仓位限制

```
单次最大仓位 = 账户余额 × 15%（针对15分钟K线）
组合最大仓位 = 账户余额 × 60%
```

### 回撤保护

```
如果 账户回撤 > 20%，暂停交易
如果 账户回撤 > 15%，仓位降低到40%
如果 账户回撤 > 10%，仓位降低到60%
```

## 📝 注意事项

1. **固定USDT模式**：每次交易风险固定，适合15分钟K线频繁交易
2. **比例模式**：根据账户余额自动调整，适合账户余额变化大的情况
3. **混合模式**：结合两者优点，根据市场状态自动切换
4. **回撤保护**：账户回撤超过20%时暂停交易，保护资金
5. **风险控制**：单笔风险不超过2%，总仓位不超过60%

## 🔄 动态调整

系统会根据以下情况动态调整仓位：

1. **DeepSeek信心度变化**：信心度越高，仓位越大
2. **信号强度变化**：信号越强，仓位越大
3. **入场时机变化**：时机越好，仓位越大
4. **市场波动率变化**：波动率越低，仓位越大
5. **趋势强度变化**：趋势越强，仓位越大
6. **账户回撤变化**：回撤越大，仓位越小
